# 00 · 前言与阅读指南

## 为什么要读这份教程

互联网上关于"AI Agent"的材料，大致分两类：一类是概念科普（"Agent = LLM + 记忆 + 工具 + 规划"），读完你只会背公式；另一类是框架文档（LangChain、AutoGPT……），读完你会调库，但不知道黑盒里发生了什么。

这份教程走第三条路：**跟着一个真实项目，从第一行代码写到最后一次发布**。

这个项目就是 One Cedric。它的开发跨度约一个月（2026 年 9 月中旬 – 10 月中旬），但浓缩了一个 Agent 产品几乎所有要面对的问题：

- 怎么和模型说话（流式、工具调用、推理模型）；
- 怎么设计工具系统，才能从 4 个工具撑到 240+ 个而不散架；
- 怎么在"让模型干活"和"别把用户电脑搞坏"之间划一条线；
- 怎么把命令行脚本变成有 WebUI、有网关、有定时任务的完整产品；
- 以及在这一切之后，怎么测试、怎么审计、怎么开源。

更重要的是，教程里几乎所有"坑"都是**真实踩过的**：不是假想的教学失误，而是作者在开发中完整粘贴过的报错堆栈、聊天记录里可查的修复过程。你会看到：

> 📅 **2026-09-19 16:06** · 开发日志（对话 #67）
>
> ```
> TypeError: Spinner.__init__() got an unexpected keyword argument 'frames'
> ```

这类时刻，才是真实开发的样子。

## 读者对象

- 会一点 Python（能读懂函数、类、字典），没写过 Agent 的人；
- 用过 ChatGPT / Claude，但想弄明白"工具调用是怎么实现的"的人；
- 想做一个自己的本地 Agent，但被"框架太多、黑盒太厚"劝退的人；
- 以及：想看看"一个高中生用一个月 + AI 协作能做出什么"的人。

你**不需要**：深度学习知识、显卡、付费 API（教程起步阶段全程使用本地 Ollama 免费模型）。

## 阅读路线图

教程按真实开发顺序组织，你可以顺序读，也可以按需跳读：

```
第一部分：起步（任何人必读）
  01 概念篇        ← Agent 的五个部件、工具调用协议、环境准备
  02 第一个 Agent  ← 500 行完整实现，逐段讲解，可复制运行

第二部分：把脚本做成软件（想深入的人读）
  03 拆包与工程化   ← 目录结构、导入系统、配置管理
  04 Rich 终端 UI   ← 流式输出、思考过程、动画的工程实现
  05 工具系统       ← schema / handler / dispatch 三层架构
  06 流式与推理     ← SSE 协议细节、DeepSeek 系模型的坑、think 档位

第三部分：Agent 的自我修养（做产品的人读）
  07 权限与安全     ← 本教程最重要的章节之一
  08 循环工程化     ← 并行、缓存、去重：让循环更快更稳
  09 大开发日       ← 一天交付十个功能模块的方法论
  10 网关与 WebUI   ← 从命令行到浏览器
  11 记忆与自动化   ← 记忆、梦境、定时、MCP、子 Agent
  12 测试与发布     ← 从"测试没意义"到 CI + 安全审计
  99 附录           ← 术语表、文件地图、报错对照表
```

每章末尾有 **「自己动手」** 环节——教程里出现的每个机制，你都能在自己的 500 行 Agent 上加一遍。

## 教程的素材与方法

本教程基于以下一手材料写成，全部为真实开发产物：

1. **三份代码快照**
   - `v1`：项目改名为 One Cedric 后、大开发日之前的形态（含流式、reasoning、@引用、LSP、computer use）；
   - `v2`：大开发日（10-01/10-02 八批交付）之后的形态（含 gateway、office 工具、memory、dream、cron）；
   - `v3`：最终开源版（Public Beta I，含 TUI、pytest 测试套件、安全审计修复、WebUI 打磨）。
2. **开发对话记录**（编号 #46–#69，2026-09-05 之后）：每一次需求、每一个报错、每一轮修复的原始记录。

引用约定：

| 形式 | 含义 |
| --- | --- |
| 📅 **开发日志 · 日期** | 来自对话记录的原始需求或报错，均可考据 |
| 代码块 + 文件路径 | 现行仓库代码（多为 v3），可直接对照阅读 |
| ⚠️ **踩坑** | 开发中真实出现的问题与修复方式 |
| 💡 **设计笔记** | 从代码中总结出的、可迁移的设计经验 |
| 🔧 **自己动手** | 建议你在自己的项目上完成的练习 |

## 开始之前：准备什么

- Python **3.10+**（教程代码按 3.10+ 语法编写，用到了 `X | None` 联合类型等特性）；
- 一个能装软件的环境（Windows / macOS / Linux 均可，教程中的报错与修复以 Windows 为主，因为 One Cedric 就是从 Windows 环境里长出来的）；
- 可选：**Ollama**（[ollama.com](https://ollama.com)），教程起步阶段的模型后端；
- 时间：第 2 章动手约需 1–2 小时，通读全教程约需 6–10 小时。

准备好了吗？下一章先花十分钟把"Agent 到底是什么"说清楚——不是背定义，而是拆开看它由哪几个零件组成。
