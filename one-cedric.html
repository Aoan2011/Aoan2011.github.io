🧑‍💻 从源码运行 / 编译

需要 Python 3.11+ 环境，推荐使用虚拟环境：

git clone https://github.com/Aoan2011/ONE-Cedric.git cd ONE-Cedric python -m venv venv # Windows venv\Scripts\activate # Linux / macOS source venv/bin/activate pip install -r requirements.txt python main.py

打包为独立可执行文件

pip install pyinstaller pyinstaller one_cedric.spec

打包产物输出到 dist/ 目录。

📋 说明

  • 终端程序，打开后在终端内运行；Windows 建议使用 Windows Terminal。
  • GitHub API存在IP限流，频繁刷新会自动切换本地 assets 静态文件。
  • 遇到问题可提交 GitHub Issue。
