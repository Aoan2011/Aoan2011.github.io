系统要求

  • 操作系统：Windows 10 及以上（64 位）
  • 无需安装 Python 运行环境
  • 建议至少 50MB 可用磁盘空间
  • 支持 Windows Terminal / CMD / PowerShell
  • LSP 功能需自行安装对应语言服务器
  • Ollama 功能需本地部署 Ollama 服务

使用说明

  • 下载后直接双击运行，无需安装
  • 若 Windows 弹出安全警告，点击「仍要运行」
  • 建议将程序放入非系统盘目录
  • 配置文件自动生成至 %USERPROFILE%/.one-editor/
  • 首次启动会显示欢迎页面引导操作
  • 遇到问题可前往 GitHub 提交 Issue
